# 新人路线以文章维护（V3.0）

来源：用户在本任务确认只保留一条路线，数量自由调整，并选择“每一步就是一篇文章”。取代 ONB-01/02/03/08 原先的固定六阶段与步骤表单。

- 管理员和编辑者共享新人路线文章列表，阅读者不能维护。
- 一行一篇文章，展示顺序、文章标题、发布状态、负责人；支持按标题搜索并添加已有文章、新建文章、编辑原文、上移下移及移出路线。
- 数量不限于六篇；同一文章不重复加入。移除关系不删除文章，空路线有清楚的空状态。
- 从路线新建和编辑文章，保存及发布后保留返回路线的入口。新建草稿可先安排到路线，阅读者只看已发布内容；编辑期间继续显示最后发布版本的标题与摘要。
- 阅读侧展示有序文章总览、动态数量，并在文章阅读页提供路线内上一篇、下一篇与返回总览。原有 stage 链接兼容跳转到迁移后的文章。
- 现有每个阶段转换为一篇文章，阶段说明、步骤标题及说明、原有文章和模板链接全部保留。迁移只执行一次，旧表保留用于核对，不清空真实数据。已有安装将迁移内容交给最早启用的管理员（无管理员则编辑者）复核，复核日期为迁移当天，保留可见性；没有管理账号的全新安装保留为草稿，补齐发布条件后发布。
- 首页、需求与验收说明去掉固定六阶段；保留现有主题配色与装饰图。
- 不新增多条路线、个人学习进度或全站后台重构。

迁移文章使用“新人学习 / 入门指南”作为默认归属，满足现有文章发布所需的主要主题；编辑者可在文章属性中重新选择。新建文章与加入路线在同一事务完成，失败不会留下未加入路线的重复草稿。

## 验证范围

通过新人路线管理模块及阅读模块的公开接口验证迁移、数量/顺序/权限/文章复用/草稿隔离；通过浏览器验证编辑者完成添加、编辑与移除流程、阅读者看到对应内容、明暗主题及窄屏可用。审查基准为实施前提交 `9a354797ddc6eace985246b4cacf1c276136aab5`。
