# 文章内容保护（V4.0）

用户于 2026-10-19 确认并授权开发。目标是限制阅读者随手复制并提供截图追溯线索，不承诺防截图、拍照、OCR、开发工具提取或水印移除。

- 文章详情（含新人路线）及品质/散热主题内联全文统一保护；正文包含图片、代码、公式、表格。模板下载保持不变。
- 所有角色阅读时显示浅色倾斜重复水印：`天脉品集 Q-Nexus · 内部资料 · Lou（账号名）· 2026-10-19`，姓名/账号取当前会话，日期为访问当日 Asia/Shanghai；缺姓名回退账号。不放会话令牌。
- 阅读者限制正文的常规复制、剪切、拖拽、右键；打印只显示「内部资料，请联系负责人获取授权副本」。不全局拦截搜索、反馈、导航、浏览器查找。编辑者/管理员保留复制及导出，后台编辑预览不受保护组件影响。
- 图片必须登录，并校验可访问的已发布内容/书目引用；编辑者/管理员可看编辑用图片。非图片扩展拒绝。私有不缓存，避免新响应进入公共缓存；无法撤回用户已有缓存或已保存文件。第一期不把个人水印嵌入原图。
- 单篇文章/全站导出记录服务端成功审计，不记录客户端复制、右键、打印尝试。
- 本地修改验证并提交 → 部署前备份 → SSH 推送部署机并部署验收 → 本机推送 GitHub 与 v4.0。更新 VERSION 和项目 Excel。


## V4.1 用户确认的修订（2026-10-19）

前台阅读不再豁免编辑者与管理员：三种角色均限制正文常规复制、剪切、拖拽、右键及打印。后台编辑器与预览保留正常操作。受控图片接口在鉴权后把当前账号姓名、用户名、上海日期水印合成到交付文件的像素中，直接打开或另存图片也带水印。存储原图、备份与已有授权导出不改变。图片响应继续 private/no-store，处理失败不回退为原图。容器安装中文字体以免水印缺字。

图片及图片链接使用带保护版本参数的地址，避开 V4.0 以前的公开长期浏览器缓存。


## V4.2 阅读体验调整（2026-10-19）

文章水印绘制在正文下方，透明度由 15% 降为 10%，移除白色描边；有不透明底色的正文块会盖住底纹。图片是扁平像素，不能还原独立文字层，改以 18% 的浅水印配合 darken 混合，避免把深色文字盖浅，并继续将账号水印写入交付文件。原图、复制和打印权限保持既有规则。
