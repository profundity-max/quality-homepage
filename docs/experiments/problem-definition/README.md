# RCA 问题定义课程

## 原文评审与学习设计

原文为用户提供的《01 RCA 问题定义》PDF，正文题名为《Define the Problem 定义问题》，维护日期 2026-09-23。阅读了导言、十四节、结语及总览图。原文最有价值的部分是优先级、范围、3W1H 与不预写原因的连续判断，以及用 Pareto、运行图、图片、Defect Mapping 和判定样支撑工程交接。原文的厚度示例适合看懂成品描述，复用为课程时增加陌生案例、阶段决策和有依据的自写交接单。

| 目标 | 独立工作及可观察产出 | 易犯的判断错误 | 怎样学 |
| --- | --- | --- | --- |
| 选题与范围 | 按既定目标用可比较的口径排出优先级，解释为什么按模式和设备分层 | 仅凭单次损失或合并后的总数决策 | 理解 Pareto 与决策矩阵的关系，反复选择适用指标 |
| What 与 Where | 用规格和判定条件描述异常，绘制同一坐标下的位置分布，区分产品位置、检出点和制造追溯点 | 用形容词代替判定，把检出工位和位置聚集写成原因 | 理解规则边界和坐标基准，练习同件对照 |
| When 与 How Much | 记录已知正常到首次已知异常的范围，报告分子分母、量值幅度和疑似批次 | 把报告时间写成起点，把总体或仓储范围当实检分母 | 记住 3W1H 和 F/T，练习核对运行顺序与计算 |
| 评审及交接 | 用六问复核一段 3W1H 自写记录，分别交接事实、附件、待验证线索和修订范围 | 提前定因、只找支持假设的证据，或在信息缺失时给出过度确定结论 | 记住评审六问，反复改写和对照已知证据 |

## 课程范围

课程复用学习中心、测验、地图、反馈及进度架构。八张教学卡与四项翻转回忆承接八道随堂题，四题前测和九题后测使用不同场景。铝壳压痕案例逐步给出七段信息，覆盖选题、定位、候选、证据、措施、验证和交接。最后要求学员撰写初始问题描述，并用清单与范例自评。自由文本草稿仅保存在当前浏览器，任务完成与选择题得分分别记录。工程能力可通过评审员复核学员在真实但适当脱敏的工作案例中提供的证据来验证。

案例为教学模拟。选题台账、300 件抽检、2,400 件疑似范围、20 件每条件的复现试验和三批各 100 件的改善验证使用各自口径。0/50 是当时抽样所得的已知观察，随后 24/300 = 8.0% 只描述变化后样本。课程区分定义与诊断，诊断后阶段是承接练习，Y 与 X 继续分开记录。ASQ 的 8D 的 D2/D4 用于校对阶段职责，Lean Enterprise Institute 的 A3 用于校对可观测的差距与事实表达。课程用时是设计估计，未测量学习增益。
