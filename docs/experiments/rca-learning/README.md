# RCA 根因分析试点

## 原文评审与学习设计

材料为本地《01 RCA 根因分析》PDF，维护日期 2026-09-22。核对了导言、九节、主线总结、围堵对照表和末尾总览图。总览图在正文之外强调了同类问题预防、稳定性、团队判断与固化推广，课程将这些内容放入知识地图、评审卡和案例收尾。

原文通过 Find It / Fix It 和证据链建立完整框架，3W1H、治具原因层级、反装案例和评审五问适合工作中快速查阅。学习模式补充先作判断再看反馈的训练，特别考查学员如何缩小边界、排除竞争解释、设计措施和审查效果证据。

| 目标 | 工程任务及可观察证据 | 关键判断差异 | 学习方式 |
| --- | --- | --- | --- |
| O1 问题与制程 | 写出异常特征、规格、时空范围、受检分母和未决信息，并提出工序前后对照 | 从异常标签与检出工位推进到可追溯边界和可能发生点 | 记忆 3W1H 和十步的两阶段结构，练习边界与工序判断 |
| O2 原因和证据 | 写出候选、可反证预测、支持与排除证据，并标明仍未覆盖的条件 | 从相关性与工具输出推进到受控比较及控制缺口 | 理解原因层级，反复设计比较和解读证据 |
| O3 原因与措施 | 匹配围堵、纠正与防再发措施，指出每项动作控制的条件 | 从一般性培训或全检推进到工程防错及持续控制 | 理解三类活动，反复做机制和措施配对 |
| O4 有效性与关闭 | 用事前标准评审批次、班次、最差条件、效果及固化，并提出欠缺证据 | 从完成任务推进到评审客观证据与后续监测 | 记忆五问，练习用五问退回或批准关闭 |

首轮课程用选择题观察工程判断。实际工作能力可用匿名报告实作验证，要求学员独立提交 O1–O4 的四类产出，由评审员逐项核对，再讨论证据不充分时的处理。试点页面呈现的是课程内表现。

页面使用既有站点的登录、壳层和配色。学习路线为知识地图 → 摸底 → 情景 → 学习、主动回忆与随堂检查 → 七阶段模拟 → 后测 → 总结与知识地图。案例分阶段揭示证据，早先的选择可回看，正式测验只在整卷提交后统一给出反馈。

案例为教学模拟。受控试验使用未加工新样件，同条件 30 件；恢复磨损销后再次出现超限。三批各 80 件的生产验证与近限值的补充 80 件分别记录，零观察仅支持已验证范围。量测核验、受控复现、最差条件和横向展开用来补充原文的执行细节。依据见对比页来源及以下资料。

- [ASQ RCA](https://asq.org/quality-resources/root-cause-analysis)
- [ASQ 8D](https://asq.org/quality-resources/eight-disciplines-8d)
- [FDA MDSAP 纠正措施和有效性验证](https://www.fda.gov/medical-devices/medical-device-single-audit-program-mdsap/mdsap-qms-p0009-nonconformity-and-corrective-action-procedure)

## 课程复用约定

- `src/modules/learning/course.ts` 定义数据结构。`rca.ts` 给出文章试点匹配、内容版本、目标、知识点、卡片、各类题目、案例、来源和覆盖矩阵。
- 每张卡聚焦一次判断，建议 80–200 字、30–90 秒。回忆卡先问后揭示，可挂接在教学卡之后。
- 保持卡片和题目 ID 稳定。评分或流程不兼容改动时更新内容版本，以独立进度开始。覆盖矩阵从关联 ID 生成题目列，原文锚点从已发布文章目录解析。
- 每道题有答案下标、逐项解析、错误选项的误区、目标、知识点、卡片、难度及认知层级。题干变化应保留目标覆盖，前后测选不同场景。
- 存储按内容版本和账号隔离。草稿与首次正式提交分离，练习保存首次及最新判断和尝试次数。以完成时间与课程的 Day 1 / 7 / 30 定义复习周期数据，用于未来调度。
