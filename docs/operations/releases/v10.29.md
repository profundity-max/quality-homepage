# V10.29 · 采购台账全宽高密度布局

日期：2026-11-23。类型：用户直接要求的小型修改。物资追溯应用升级 V1.2.9。

## 变更摘要

- 采购台账页单独启用全宽布局，取消 1280px 主内容宽度限制。
- 表格容器高度提升到视口可用高度，桌面端可显示更多采购记录。
- 40列表格改为自适应列宽，降低强制最小宽度并压缩单元格内边距和字号。
- 长文本最多显示两行，完整内容通过鼠标悬停提示查看，减少行高膨胀。
- 页面切换离开采购台账时自动恢复常规内容宽度。

## 验证范围

- 1920×900：主区域宽度 1920px，表格区域无横向滚动，可视约11行。
- 1440×900：表格仅约12px横向溢出，可视约9行。
- 采购台账操作按钮、审核/核准状态和全宽布局显示正常。
