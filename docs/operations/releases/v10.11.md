# V10.11 CQE 良率分析网站受控接入 · 2026-11-12

应用中心新增「CQE 测试线良率分析」卡片。点击后进入品集说明页，再由 `/apps/cqe-yield-analysis/launch` 签发短期访问授权并跳转到原良率分析网站。原网站继续在原对话区域维护，本次不迁移、不复制其业务代码和数据库。

## 访问控制

- 品集登录用户才能申请入口授权。
- 授权令牌使用 HMAC-SHA256 签名，绑定应用标识、品集用户和过期时间，有效期 2 小时。
- 原站 Nginx 对所有页面、静态资源和 API 执行 `auth_request`，转发授权令牌到品集访问校验接口。
- 首次入口由原站 Nginx 校验令牌后设置原站专属 HttpOnly、Secure、SameSite=Lax Cookie；后续请求持续校验该 Cookie。
- 未携带有效授权直接访问原站时，返回品集 `/apps/cqe-yield-analysis?access=expired`，不会进入原站登录页或业务页面。
- `/api/v1/health` 保持独立健康检查，不作为业务入口。
- 原站自身账号、角色、数据导入和分析逻辑保持不变，仍需使用原站账号登录。

## 验收范围

- 应用中心显示 CQE 卡片并可进入说明页。
- 未登录调用启动接口时返回品集登录页。
- 登录后启动接口返回原站 `/__qnexus_entry` 和有效签名授权。
- 品集访问校验接口接受有效令牌、拒绝篡改和过期令牌。
- 原站网关拒绝无授权直接访问，放行有效原站授权 Cookie。
- 桌面、手机、浅色和深色页面无横向溢出，并完成严重级可访问性检查。
