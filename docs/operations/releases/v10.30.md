# V10.30 · 采购台账OA风格表格精修

日期：2026-11-23。类型：用户直接要求的小型修改。物资追溯应用升级 V1.2.10。

## 变更摘要

- 采购台账40列表头改为横向整齐排版，所有业务列设置明确宽度，避免窄列文字逐字竖排。
- 长文本列加宽，短字段收窄；文本左对齐，数量、单价、现有数量和已到货数量右对齐。
- 表头统一高度并吸顶，数据行统一52px行高，单元格间距一致。
- 数据行增加浅色隔行背景，悬停时高亮。
- 序号列固定在左侧，操作列固定在右侧；中间38列支持横向滚动。
- 状态继续使用黄色、蓝色、绿色、红色标签区分。
- 编辑、删除、审核、驳回、核准和重新提交按钮统一尺寸、圆角和间距。
- 页面保持全宽，整体采用简洁的OA台账风格。

## 验证范围

- 40列表头均横向显示，无逐字竖排。
- 序号列在横向滚动后保持左侧固定，操作列保持右侧固定。
- 数据行高度统一52px，隔行底色和悬停高亮正常。
- 状态标签颜色正常，操作按钮尺寸一致且不溢出冻结列。
- 表格内容区支持横向和纵向滚动，表头固定。
