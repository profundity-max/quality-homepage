# V4.1 内容保护修复 · 2026-10-19

## 原因与修改

V4.0 的前台保护按角色只限制阅读者，管理员和编辑者明确豁免。用户本次确认三种角色前台均受限，后台编辑继续可用。独立文章和主题内联正文统一采用新规则，CSS 对正文子元素一并禁选，避免子元素重启文字选择。

原图片接口只检查授权，随后返回原始字节。网页伪元素水印不会写入图片文件，因此另存后没有水印。本版使用 sharp 在鉴权后把身份水印平铺合成到交付像素，按当前会话及上海日期生成。保留 PNG/JPEG/WebP/GIF 格式、尺寸及 EXIF 方向显示，存储原图和既有授权导出不改。服务器安装 Noto 中文字体；失败返回私有错误，绝不回退交付原图。

本版没有 schema 迁移。前台防复制提高常规操作门槛，仍不能阻止截图、OCR 或技术提取；既有已保存原图无法撤回。

- 6 项浏览器测试通过，含三种角色在独立文章和主题页真实快捷键复制、全选复制的剪贴板验证，后台编辑预览、反馈与打印、手机明暗主题。追加后台源码真实复制的正向对照，单项复跑通过（7.2 秒），确认剪贴板检查可捕捉正常复制。

## 线上验收发现的旧缓存修复

Ego Lite 实际下载原地址时命中 2026-10-13 的旧响应，仍带 `public, max-age=31536000, immutable`。这会绕过服务器已经部署的鉴权和水印。所有渲染后的正文图片、图片链接和书封面统一增加 `protected=4.1`，主动避开旧缓存，不依赖读者手动清缓存；新响应继续按账号 private/no-store。存储中的 Markdown 和原文件地址不改动。

新增缓存地址回归先失败后通过；重跑 Markdown、图片权限、书目、迁移和图片 HTTP 边界共 6 文件、33 项通过。线上实际下载新地址已确认返回私有不缓存，保存文件内中文、姓名、账号、日期水印清晰存在，原图 SHA-256 保持不变。后续部署使用相同依赖层，重新构建应用并再次验收。
