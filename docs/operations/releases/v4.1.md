# V4.1 内容保护修复 · 2026-10-19

## 原因与修改

V4.0 的前台保护按角色只限制阅读者，管理员和编辑者明确豁免。用户本次确认三种角色前台均受限，后台编辑继续可用。独立文章和主题内联正文统一采用新规则，CSS 对正文子元素一并禁选，避免子元素重启文字选择。

原图片接口只检查授权，随后返回原始字节。网页伪元素水印不会写入图片文件，因此另存后没有水印。本版使用 sharp 在鉴权后把身份水印平铺合成到交付像素，按当前会话及上海日期生成。保留 PNG/JPEG/WebP/GIF 格式、尺寸及 EXIF 方向显示，存储原图和既有授权导出不改。服务器安装 Noto 中文字体；失败返回私有错误，绝不回退交付原图。

本版没有 schema 迁移。前台防复制提高常规操作门槛，仍不能阻止截图、OCR 或技术提取；既有已保存原图无法撤回。
