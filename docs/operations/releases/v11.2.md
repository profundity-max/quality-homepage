# V11.2 · 物料下发增加隶属区域负责人

日期：2026-11-25。类型：用户直接要求的小型修改。物资追溯应用升级 V1.2.12。

## 变更摘要

- 物料下发保留成员名单中的“领用人”选择。
- 原“领用部门”字段改为可手动输入的“隶属区域负责人”。
- 隶属区域负责人允许自由填写姓名，不限制必须来自成员名单。
- 领用人所属部门仍自动写入分发记录，用于兼容原有查询和导出。
- 分发列表、领用签字页、分发导入模板和 Excel 导出的对应字段统一改为“隶属区域负责人”。
- 历史分发记录没有新字段时继续回退显示原领用部门值。
- 新增面向同事的 Word/PDF 操作说明，覆盖登录、角色、申领、审批、到货签收、物料下发、领用确认和常见问题。

## 验证范围

- 分发记录同时保存领用人、隶属区域负责人和自动带入的部门。
