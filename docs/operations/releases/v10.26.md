# V10.26 · 采购台账 Excel 导出导入

日期：2026-11-23。类型：用户直接要求的小型修改。物资追溯应用升级 V1.2.6。

## 变更摘要

- 采购台账页新增“导出 Excel”和“导入 Excel”。
- 导出文件包含当前筛选采购台账、空白采购导入模板及填写说明三张工作表。
- 导入模板按采购手填项目设置：存货编码、物料名称、规格型号、单位、物品分类、采购数量、采购日期、用途说明、使用去向、申请部门、请购来源。
- 采购台账页可直接导入 `.xlsx/.csv`；优先读取“导入模板”工作表。
- 导入物料不存在时自动创建物料档案；采购数量、日期和请购来源由导入程序校验。
- 导入采购继续按当前登录人的成员名单自动路由，不绕过审核和核准。
- 设置页的采购导入也复用同一套校验与路由逻辑。
- 修复 XLSX 中文单元格以数字字符实体存储时无法识别的问题。

## 验证范围

- 导出的 Excel 工作表、表头和当前采购台账内容通过检查。
- 在导出模板回填一行后重新导入成功。
- 同时导入已有物料和新物料成功，新物料自动建档并进入待审核。
- 浏览器验证采购页导出、导入按钮及导入结果弹窗。
