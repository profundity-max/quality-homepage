# V10.16 · 物资申领与消耗追溯应用接入

日期：2026-11-18。类型：用户直接要求的小型修改与既有项目优化。

## 变更摘要

- 审查物资申领追溯系统 V1.1.0，并将其业务与安全结构升级为 V1.1.1。
- 应用中心新增“物资申领与消耗追溯”卡片、说明页、受控启动接口和访问校验接口。
- 生产运行采用品集 SSO：`administrator → 管理员`、`editor → 文员`、`reader → 区域领用人`。
- Nginx 通过 `auth_request` 保护 `/wz/` 下全部页面、静态资源和 API；无有效品集 Cookie 时返回应用说明页。
- 应用数据保存在品集受控数据卷内，由既有加密备份一并覆盖。

## 业务与安全优化

- 拆分模型合并、业务规则、身份解析、持久化审计和 HTTP 路由。
- 未签收批次禁止分发；累计到货、实收、分发和采购数量均有服务端上限校验。
- 同一到货批次只能签收一次，同一分发单只能签字一次。
- 区域领用人只能确认所属区域，签字人必须与品集登录身份一致。
- 新增服务端 `audit.jsonl`，客户端活动日志不再作为权威审计。
- 整库恢复改为管理员专用接口，要求明确确认，并生成墓碑防止旧客户端复活记录。
- 主数据文件损坏时拒绝启动，避免空数据静默覆盖。
