# V11.7 · 分发区域清单更新

日期：2026-11-25。类型：用户直接要求的小型修改。物资追溯应用升级 V1.2.13。

## 变更摘要

- IPQC2/IPQC3 内部标识保持不变，显示名称分别改为 MP IPQC、NPI IPQC。
- 原量测室拆分为二期量测室、三期量测室。
- 原实验室拆分为二期实验室、三期实验室。
- 新增 QPM、AIM、SQE、PQE、品质办公室区域。
- 保留 OQC、IQC 以及管理员已有自定义区域。
- 旧量测室、实验室不再出现在新建区域下拉选项，但历史单据继续显示“量测室（历史）/实验室（历史）”。
- 浏览器区域配置升级到 schema version 2，旧配置自动迁移，无需每位同事手动维护。

## 验证范围

- 新用户区域下拉和仪表盘显示更新后的13个标准区域。
- 旧配置自动迁移，IPQC名称更新、旧量测/实验室移除、新区域增加，自定义区域保留。
- 成员区域选择和分发区域选择同步使用新清单。
- 历史区域标签仍可显示。

## 发布状态

待备份并部署至 `quality-server.local`。
