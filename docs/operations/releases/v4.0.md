全量检查暴露既有统计测试的固定时钟问题：fixture 的 NOW 为 2026-08-19，构造的 30 天前记录在实际 2026-10-19 已超过真实 90 天窗口。只在该测试中把 Date.now 固定到其自身 NOW 并在 afterEach 恢复；不修改生产统计逻辑。

## 运行与保护边界

- 本地开发验证、提交后经 SSH 部署并验收，再由本机推送 GitHub 和 v4.0。
- 升级无 schema 迁移，部署前保存加密备份；原数据库和数据卷继续使用。
- 本功能不是 DRM，不能阻止拍照、OCR、技术提取或水印移除。水印是账号线索而非实际泄露人的证明；不监控截图或将浏览器复制尝试当作证据。
- 新响应 private/no-store 不会撤回已有公共缓存和已保存原图；本期不把个人水印嵌入原图。
- 图片授权通过 SQL 先筛选包含 UUID 的可读正文，再复用最终渲染树；当前项目规模下没有发现性能阻断，尚未进行大规模容量压测。
