# V10.9 BOF 应用集成 · 2026-10-30

应用中心由占位页升级为可用应用目录，首批接入「BOF 箱线图与散点图 V1.1」。用户从应用卡片进入说明页，可查看工作簿结构、四步使用说明、案例数据摘要，并下载包含 Data、Spec、BinPlot、HL SN 的 XLSX 案例工作簿。

BOF 工具运行页与案例下载接口均要求品集登录；实际 BOF 页面保持 V1.1 原构建文件不变，工作簿仍只在浏览器本地处理，不上传服务器。Docker 运行镜像新增 `app-assets` 目录复制，保证生产环境可以读取受控工具与案例文件。

## 验收范围

- 应用中心显示一个可点击的 BOF 应用卡片，并进入独立说明页。
- 说明页提供案例下载、工具打开入口、输入字段与四项操作说明。
- BOF 运行页未登录时跳转登录；登录后可加载 V1.1 工具。
- 案例工作簿可以通过 BOF 校验并生成 2 张图。
- 页面适配桌面与手机、浅色与深色主题，并完成自动化可访问性检查。
- 构建、类型检查、Lint、模块与集成测试结果在交付回复中如实列明。

## 本地验收结果

- `npm run format:check`、`npm run typecheck` 通过；ESLint 无错误，保留 2 项既有警告。
- `npm run test:local`：73 个测试文件、424 项测试通过。
- `npm run test:postgres:container`：6 个测试文件、19 项测试通过。
- BOF 专项 Playwright：3 项通过，覆盖卡片进入、说明页、受保护运行页、案例下载、案例导入生成 2 张图、320/768/1440 响应式、浅深主题和严重级无障碍检查。
- `npm run test:e2e` 全量：130 项通过、1 项跳过、3 项既有非 BOF 用例失败。失败项分别是书单分类标签定位、主题文章索引定位和品质知识页文本预期，与本次应用中心及 BOF 代码无关联。
- `npm run build` 与 Docker `runner` 镜像构建通过；镜像内已确认存在 BOF 运行文件和案例工作簿。
- 人工截图复核应用中心、BOF 说明页和手机深色布局；BOF 案例导入后在工具中生成 2 张图。
