# V10.9 BOF 应用集成 · 2026-10-30

应用中心由占位页升级为可用应用目录，首批接入「BOF 箱线图与散点图 V1.1」。用户从应用卡片进入说明页，可查看工作簿结构、四步使用说明、案例数据摘要，并下载包含 Data、Spec、BinPlot、HL SN 的 XLSX 案例工作簿。

BOF 工具运行页与案例下载接口均要求品集登录；实际 BOF 页面保持 V1.1 原构建文件不变，工作簿仍只在浏览器本地处理，不上传服务器。Docker 运行镜像新增 `app-assets` 目录复制，保证生产环境可以读取受控工具与案例文件。

## 验收范围

- 应用中心显示一个可点击的 BOF 应用卡片，并进入独立说明页。
- 说明页提供案例下载、工具打开入口、输入字段与四项操作说明。
- BOF 运行页未登录时跳转登录；登录后可加载 V1.1 工具。
- 案例工作簿可以通过 BOF 校验并生成 2 张图。
- 页面适配桌面与手机、浅色与深色主题，并完成自动化可访问性检查。
- 构建、类型检查、Lint、模块与集成测试结果在交付回复中如实列明。
