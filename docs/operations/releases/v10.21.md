# V10.21 · 成员导入物料档案

日期：2026-11-18。类型：用户直接要求的小型修改。

## 变更摘要

- 物资追溯应用升级 V1.2.3。
- 设置页“Excel 导入 → 物料档案”从仅管理员可用，调整为成员名单中的已登记人员均可使用。
- 成员可批量新增或按存货编码/物料名称更新物料档案。
- 新增专用 `/api/import/materials` 受控接口，仅允许管理员或成员名单中启用且已登记的人员调用。
- 普通成员仍不能手工新增、编辑或删除物料；物料档案手工维护权限继续仅限管理员。
- 物料页“导入 OA 模板”入口同步对已登记成员开放。

## 版本说明

工作区存在另一个尚未提交的 V10.20 BOF 发布说明，为避免覆盖并行工作，本次版本使用 V10.21。
