# V10.0 完整现代编辑型UI · 2026-10-29

V9.0只替换独立文章阅读页，首页和分类内联阅读仍是旧界面，未满足完整设计交付。本版将已确认的现代编辑型设计应用到整个门户。

首页采用专题标题与图解、真实搜索、知识分类、最近更新和新人学习入口。分类与文章来自发布数据，不照搬设计图的示例条数或标题。知识栏目继续整篇内联阅读，增加可见栏目/主题、真实分类树及正文目录，多篇文章拥有独立锚点；窄屏可展开分类与目录。独立文章保留V9布局、内容保护、元信息、收藏反馈和阅读计时。

新人路线、书单、模板列表/详情、完整搜索、收藏、登录使用统一Editorial字体、色彩和排版；后台保留结构化管理控制台，基础配色与控件随全站浅深主题。完整搜索筛选可展开、应用并重置；快速搜索支持正确主题入口、默认不选中、中文输入法、请求取消与竞态保护、失败重试、焦点及背景隔离、同页导航关闭。

首页图解为同均值、不同标准差的正态分布示意，不能从曲线形状判断过程受控。浅/深图解使用独立资产。没有依赖或数据库结构变更。
