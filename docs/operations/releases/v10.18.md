# V10.18 · 成员名单 Excel 导入

日期：2026-11-18。类型：用户直接要求的小型修改。

## 变更摘要

- 物资追溯应用升级 V1.2.1。
- Excel/CSV 导入目标新增“成员名单”。
- 支持批量导入：姓名、品集账号、业务角色、所属区域、所属部门、上级区域领用人、启用状态。
- 支持审核员、核准员、区域领用人、隶属区域领用人四类业务角色。
- 隶属区域领用人先按姓名匹配同区域的区域领用人作为上级；支持同一文件中先导入上级、再导入下属。
- 成员导入继续仅允许系统管理员武欣雨执行。
- 全量台账 Excel 新增“成员名单”工作表，可与导入模板形成往返闭环。
