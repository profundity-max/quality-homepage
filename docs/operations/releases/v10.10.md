# V10.10 BOF 可选 BinPlot 与 Spec 上下限 · 2026-10-30

BOF 箱线图与散点图由 V1.1 升级至 V1.2。`BinPlot` 从必需工作表调整为可选：缺少 `BinPlot`，或只有表头而没有数据行时，工具仍可完成分析；图表不再生成 Bin 背景色带、Bin 边界和 Bin 名称，而是按每个尺寸分别绘制 `Spec` 中的 USL/LSL 上下限。

提供有效 `BinPlot` 的既有工作簿继续使用原有 Bin 模式，Bin 连续性、覆盖范围、颜色、色带和边界行为保持不变。

## 品集侧变更

- 应用中心 BOF 卡片版本更新为 V1.2，摘要说明无需分 Bin 数据。
- 应用说明页将必需工作表改为 Data、Spec、HL SN，并明确 BinPlot 可选及两种图表模式。
- 案例工作簿删除 BinPlot 页签，使用 4 个尺寸、2 个 BinType、8 个 SN 和 2 个 Highlight SN 演示 Spec-only 模式。
- 案例工作簿的“使用说明”页说明 BinPlot 可选，以及缺少时只画 USL/LSL。
- BOF 受控运行文件替换为 V1.2 单文件构建。

## 验收范围

- 无 BinPlot 和只有表头的 BinPlot 工作簿均成功解析。
- Spec-only 模式输出 8 条上下限线、0 个 Bin 色带、0 条 Bin 边界。
- 含 BinPlot 的既有真实样例继续输出 8 条 Bin 边界线和 32 个 HL 标签。
- 案例下载后可在品集 BOF 页面生成 2 张图。
- 桌面、手机、浅色模式、PNG 下载、`file://` 离线运行和可访问性边界通过。
