# V10.23 · 品集身份自动绑定与采购审批自动路由

日期：2026-11-19。类型：用户直接要求的小型修改。物资追溯应用升级 V1.2.4。

## 变更摘要

- 用户从品集应用中心登录后，以品集账号优先、历史数据以姓名兜底自动匹配成员名单，并只读带出部门、业务角色、区域和上级。
- 未匹配成员名单的账号允许只读查看，但禁止提交采购、审批、到货签收、分发和领用签字，并明确提示联系管理员武欣雨。
- 成员名单新增指定审核人、指定核准人和审批模式，支持两级审批、仅审核、直接核准三种路由。
- 采购提交时固化审批路由快照；审批按钮和待办按当前指定审批人过滤，服务端再次校验分配关系与业务角色。
- 审批人不能修改申请人的采购业务内容；驳回原因必填；审核人、核准人、审批意见和驳回原因写入操作日志与服务端审计。
- 成员名单 Excel/CSV 模板、导入和全量导出新增指定审核人、指定核准人和审批模式列。
- 修复品集 SSO 首屏异步身份加载期间错误弹出本地“设置我的身份”窗口的问题。

## 业务基线

1. 两级审批：提交后「待审核」→ 指定审核人通过后「待核准」→ 指定核准人完成后「已核准」。
2. 直接核准：提交后跳过审核，直接进入「待核准」。
3. 仅审核：提交后「待审核」，指定审核人通过后直接完成审批。
4. 未配置审核人 / 核准人或提交人未匹配成员名单时，服务端拒绝提交。
5. 在途单据使用提交时快照，后续调整成员名单不改变审批人；驳回后重新提交按当时名单重算路由。
