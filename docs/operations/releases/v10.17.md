# V10.17 · 物资追溯角色与审批流升级

日期：2026-11-18。类型：用户直接要求的小型业务修改。

## 变更摘要

- 物资追溯应用升级 V1.2.0。
- 业务角色调整为：审核员、核准员、区域领用人、隶属区域领用人。
- 系统管理员固定为武欣雨，独立于四个业务角色；只有武欣雨可以维护成员名单、部门和区域。
- 采购新增两级审批：待审核 → 待核准 → 已核准；任一审批环节均可填写原因驳回。
- 未核准采购不能登记到货；已核准采购普通用户不能直接修改。
- 分发时必须指定区域内的领用人。区域领用人可确认本区域单据，隶属区域领用人只能确认分配给本人的单据。
- 成员记录新增品集账号、启用状态、上级区域领用人；隶属区域领用人必须绑定同区域上级。
- 品集角色默认映射调整为：管理员→核准员、编辑者→审核员、阅读者→区域领用人；成员名单中的业务角色优先。
