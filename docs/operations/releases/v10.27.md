# V10.27 · 采购台账沿用OA请购模板

日期：2026-11-23。类型：用户直接要求的小型修改。物资追溯应用升级 V1.2.7。

## 变更摘要

- 采购台账导出的“导入模板”工作表改为物料档案现有“OA请购提报 V1.0”的34列表头。
- 采购页导入可直接读取 OA 模板中的存货编码、存货名称、规格型号、单位、物品类型、请购数量、申请时间、申请部门、申请原因和地点等字段。
- OA模板没有“请购来源”列，导入时默认归为“OA请购”；行政请购和其他来源仍可在采购台账中编辑。
- 保留“采购台账”快照和“填写说明”工作表；导入优先读取“导入模板”工作表。
- 物料不存在时继续按 OA 行信息自动创建物料档案，并沿用当前成员的审批路由。
- 设置页“采购记录”模板和导入逻辑同步切换为 OA 34列表头。

## 验证范围

- 采购页导出文件包含34列 OA 模板，表头与物料档案 OA 模板一致。
- 在 OA 模板中回填一行采购数据后导入成功。
- 导入后的数量、日期、部门、用途、地点、OA来源和审批路由正确。
- 未匹配物料自动建档成功。
