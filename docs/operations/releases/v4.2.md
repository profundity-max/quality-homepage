# V4.2 阅读水印调整 · 2026-10-19

## 修改

用户反馈水印叠在文字上影响阅读。文章伪元素改为隔离容器内的负层级，绘制于正文下方；默认透明度由 15% 降到 10%，移除白色描边。代码块、Callout 等有不透明背景的内容会盖住底纹。

图片无法恢复出独立的文字层，使用更浅的 18% 身份水印与 darken 混合，避免把深色文字盖浅。交付文件仍带有姓名、账号和上海日期水印；原始图片不改动。复制、右键、拖拽和打印规则沿用 V4.1。

## 验证

新增像素回归在旧实现上失败：原本 RGB(16,16,16) 的深色区域被白描边和覆盖水印抬高到约 RGB(101,103,105)。修复后要求深色像素不被盖浅，允许 libvips 混合的微小取整误差，同时浅背景必须仍包含可见水印。

手机浅/深主题和实际图片已经查看对比。水印与图片 HTTP 边界共 16 项通过，包含深色像素不被盖浅、浅背景继续带水印、格式/尺寸、EXIF 方向、身份隔离和授权。6 项浏览器检查通过（30.2 秒），包含底纹层级、三种角色真实复制阻止、后台复制成功、打印及手机主题。lint 为 0 错误、4 条既有警告；类型检查、生产构建通过。Excel 追加第 48 行及第 42 行并查看。
