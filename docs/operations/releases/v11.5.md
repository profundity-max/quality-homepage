# V11.5 RCA 问题定义课程

日期 2026-11-25。类型为小型修改。基线为 V11.4 的 `3a5776f`。

在学习中心新增《RCA 问题定义》。课程路径为选对问题、切准范围、用 3W1H 量化事实、按六问评审交接。学员可做七阶段铝壳压痕案例，在最后撰写自己的问题描述并查看对照范例。使用已发布原文的稳定 ID `article-3f3ed646`，原文仍从既有阅读系统访问。改版对比提供 10 个维度并覆盖 17 个原文节点。课程设计及教学扩展来源见 [设计与复用规范](../../experiments/problem-definition/README.md)。

## 五维 QA

| 维度 | 验收内容 |
| --- | --- |
| 专业准确性 | 按题目标注选题口径，区分检出点、追溯点和发生点，时间记录使用已知观察区间。尺规采用联合条件，压痕分布为 21+1+1+1=24 件，变化后抽检为 (8+16)/(100+200)=8.0%，三批 2,400 件列为疑似范围。原因、纠正和验证使用独立资料。模拟阈值和验收批次均为教学设定。 |
| 教学设计 | 保留原文的四个工作动作，加入可复核交接产出。每个模块有对应教学卡、随堂题、前后测或模拟中的多次观察。总结区提供分模块判断表现、初次记录和回顾卡。实际工程胜任度须另由现场或报告产出验证。 |
| 题目质量 | 28 道题按认知层分布为 3/5/12/8，约为 11%/18%/43%/29%。题目标注 ID、知识点、目标、难度、认知层、正确选项、错因和回顾卡。前测与后测场景各异；案例设计支持复练，保留首次记录。 |
| UI 与可用性 | Chromium 桌面及 390 px 手机截屏，通过首页、目录、案例数据表和学习结果。检查了移动端横向溢出、键盘操作翻转卡，以及课程首页 Axe WCAG A/AA。 |
| 功能 | 浏览器跑通两门课，从学习中心进入、刷新续学、错题重练、七阶段按题解锁、手写草稿保存、交卷后出解析、改版矩阵回跳、无课程文章的 404 保护。生产原文的 14 个节号、导言、结语及图解定位条件已只读核对。 |

课程 UI 和交互使用隔离库的合成文章记录验收。正式原文正文、图表及数据仍由已有发布记录提供。无学习保持率或实际能力提升测量。
