# V10.20 BOF 混合 Bin 与一尺寸一图 · 2026-11-18

BOF 箱线图与散点图由 V1.2 升级至 V1.3，支持同一工作簿内同时使用 Bin 模式和 Spec-only 模式。

## 业务规则

- BinType 有值且 BinPlot 完整：保留 Bin 色带、边界、名称和原校验规则。
- BinType 有值但 BinPlot 缺失：该 BinType 自动降级为 Spec-only。
- BinPlot 行字段不完整、颜色无法识别、区间不连续或未覆盖 Spec：只禁用对应 BinType，不阻断整个工作簿。
- Spec 的 BinType 空白：不报错，每个尺寸单独一张图，只显示该尺寸的 USL/LSL。
- Blank BinType 图表标题和下载文件名使用尺寸名称。
- 其他 BinType 的正常数据不受某个 BinType 降级影响。

## 品集侧变更

- 应用中心 BOF 卡片更新为 V1.3。
- 应用说明页补充混合模式、自动降级和一尺寸一图规则。
- 案例工作簿包含五种尺寸：Group A 完整 Bin、Group B 不完整自动降级、尺寸 D/E BinType 空白独立图。
- 受控 BOF 单文件替换为 V1.3 构建。

## 验收范围

- BinPlot 部分填写、错误颜色、重复/不连续区间只降级对应 BinType。
- 原有完整 BinPlot 样例继续通过。
