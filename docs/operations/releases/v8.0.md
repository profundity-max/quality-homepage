# V8.0 后台结构化控制台 · 2026-10-22

## 变更摘要

统一后台分组侧栏、面包屑、标题尺度、页面间距与按钮层级；保留品牌、返回门户、主题切换和角色权限。800px及以下使用可展开导航，表格在内部横向滚动。

账户管理改为紧凑表格、姓名/账号与角色/状态筛选，每页20条分页。新建、身份/角色编辑与密码/停用/恢复/测试标记等操作按需进入原生模态表单，保留原服务端限制和审计。文章管理改为列对齐表格，归档时再输入原因，待复核任务移至文章管理，复核完成返回文章页。学习统计先展示四项核心指标与最多六人的摘要；访问和登录汇总仍可见；全部原有视图、实名明细、趋势、导出和清理入口保留。

无新依赖、数据库迁移或采集口径变更。管理员/编辑者/阅读者权限、测试账号排除、当前收藏口径、两年实名保留、停用和恢复会话规则不变。编辑器保留原工作区结构。设计决定见ADR0014，视觉验收见根目录design-qa.md。
