# V7.0 架构深化三项 · 2026-10-22

## 变更摘要

1. 活跃阅读会话拥有文章切换、暂停、节流、请求序列和在途请求协同；ReadingTracker 只采样 DOM 和浏览器事件。等待旧文章停止时更新选择，不再启动已过时的中间文章。保留10秒心跳、5分钟闲置、服务器20秒租约与计时口径。
2. 人员导出使用专用汇总路径，跳过文章/模板元数据和内容、趋势、明细构建；完整报表使用人员、文章、日期分组索引。知识缺口独立查询，页面不再为单个字段执行旧 dashboard 的其余6组查询。姓名筛选、跨午夜、当前收藏、权限与导出审计口径保持一致。
3. 编辑草稿会话统一自动保存、本地恢复、冲突、revision 与清理。保存响应只确认已提交快照，在途继续输入另存本地；离线初始化不覆盖已有恢复副本，未决冲突不捕获旧正文，选择服务器版本后销毁不会重建丢弃的副本。本地存储不可用仍允许服务器保存，并如实提示存储失败。浏览器离页捕获未提交正文，异步响应在销毁后不再更新界面。

## 兼容与设计

无新依赖、数据库迁移或统计口径变化。既有学习参与明细、账号和文章版本保持可读。ADR 0013 补充职责划分，ADR 0011 的服务器事务和编辑占用、ADR 0012 的采集与两年保留约定继续生效。浏览器临时正文仍只保存正文，不承诺完整离线编辑器；浏览器强制关闭或清理存储仍可能丢失未提交输入。
