# V11.4 · 应用中心新增 IPQC 时效看板入口

日期：2026-11-25。类型：用户直接要求的小型修改。基线为品集 V11.3。

## 变更摘要

- 应用中心新增“IPQC 时效看板”应用卡片。
- 点击卡片时先校验品集登录状态，再跳转到指定 IPQC 时效看板地址。
- 未登录用户返回品集登录流程，登录后继续进入看板。
