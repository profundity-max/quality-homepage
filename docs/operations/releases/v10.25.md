# V10.25 · 双系统管理员与品集账号回填

日期：2026-11-23。类型：用户直接要求的小型修改。物资追溯应用升级 V1.2.5。

## 变更摘要

- 系统管理员由武欣雨扩展为武欣雨、熊光芬；两人均可维护成员名单、部门、区域和物料档案。
- 前端管理员提示改为从服务端读取管理员名单，不再固定显示单一管理员姓名。
- 生产成员名单回填品集账号：Lou、熊光芬、武欣雨；熊光芬登录后按账号自动关联品质部、区域领用人角色和 IPQC2 区域。
- 为熊光芬配置可运行审批路由：武欣雨审核 → Lou 核准，解决“未配置审核人，请联系管理员”导致无法提交采购的问题。
- 采购审批、指定审批人和职责分离规则保持不变，不因系统管理员身份绕过审批分配。

## 技术变更

- `WZ_SYSTEM_ADMIN_NAMES` 改为 `武欣雨,熊光芬`。
- 身份接口向已登录用户返回系统管理员名单，前端据此显示管理员提示。
- 成员维护仍只允许系统管理员执行；非管理员调用继续由服务端拒绝。
- 版本号：品集 V10.24 → V10.25，物资追溯 V1.2.4 → V1.2.5。

## 验证范围

- 物资追溯 Node 测试与语法检查通过。
- 熊光芬 SSO 身份验证：成员匹配成功、部门/区域自动带出、系统管理员权限生效、成员维护入口可见。
- 熊光芬采购表单验证：自动显示“审核：武欣雨 → 核准：Lou”，可正常提交。
- Compose 契约与类型检查通过。
