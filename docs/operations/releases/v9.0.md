# V9.0 文章阅读模板首批 · 2026-10-28

## 变更摘要

在文章详情及归档说明试点 Editorial 设计系统：限域浅深色 Token，桌面真实知识树/正文/目录，手机单栏与紧凑导航，元信息排在正文之前。保留收藏反馈、版本权限、阅读计时、新人路线来源和内容保护。

修复 KaTeX 输出被后置清洗破坏的排版，先清洗 Markdown 再以 trust:false 渲染；Mermaid 响应内容及主题变化；宽表、代码和块公式局部横滚。按用户确认，仅将新版文章浅色 Warning 标题改为 #96672D，对比度提高到4.63:1，深色与其他页面原色不变。

首页、分类内联、搜索及后台不进行本批视觉重构。无新依赖和数据库迁移。详见 [本地验收](../../design/editorial-reading-v9.0/acceptance.md)、[已确认设计](../../design/editorial-reading-v9.0/handoff.md)、[实施计划](../../design/editorial-reading-v9.0/implementation-plan.md)。

应用和测试提交范围：`e9553fc` 至 `4d9bc34`；包含版本、Excel和验收资料的后续记录提交为本地V9.0完整快照。
