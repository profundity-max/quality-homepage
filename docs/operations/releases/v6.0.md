# V6.0 管理员学习参与统计 · 2026-10-21

## 变更摘要

- 管理员从「管理 → 学习统计」进入总览、人员、内容三个视图。支持上海时区月、季、年、自定义日期、姓名搜索和分项排序；正式成员无活动也列出，停用账号保留历史并标状态。
- 文章访问、有效阅读次数和人数、有效篇数、活跃阅读时长、当前收藏数量；模板跨版本下载次数和人数，实名明细显示人员、时间和模板版本；成功登录次数、最近登录、最近活跃与活跃天数。所有明细支持筛选、25条分页，不提供个人收藏清单和自动学习总分。
- 所有前台阅读角色与文章/主题正文均采集。前台可见且有焦点，连续5分钟无交互暂停；累计30秒为有效阅读，同人同文30分钟去重。服务端时钟、用户行锁、20秒租约、顺序请求和序列重试去重，避免多标签重复；暂停结算有效尾段，网络超时不推造时长。
- 账号停用立即撤销会话，恢复沿用身份和历史、原会话不复活；管理员可显式标记测试账号排除统计，操作审计。原有内容负责人重分配与最后管理员保护继续生效。
- 管理员可导出日期/姓名/排序范围内人员汇总XLSX，写入导出审计；表格文字不作为公式执行。页面、旧CSV、实名导出及审计中的实名行为均落实管理员边界，编辑者仍可查看内容维护审计。
- 实名统计细节保留两年，启动后及每天自动清理，后台和CLI共享口径，禁止误清保留期内数据；匿名累计不改写。安全与内容审计继续执行独立的不可变审计策略。按用户要求无首次登录说明弹窗。

## 数据与兼容

0018 新增阅读会话、计时片段、全用户阅读租约、首次采集起点和测试账号标记，可重复执行且不重设起点。所有既有账号默认纳入。仅正式已发布阅读投影可采集，不接受客户端提交用户身份或秒数。LAN HTTP不依赖仅HTTPS可用的randomUUID。

历史访问/下载/登录只展示仍存在的记录，旧90天保留规则删除的明细无法恢复；旧阅读也曾排除管理员和编辑者，不追造该部分。历史时长、有效阅读无法补算，完全早于采集起点时显示“未采集”，跨起点说明仅采集上线后部分。跨日达到有效阅读或继续产生时长时补入关联访问明细，访问次数仍归首次访问日期。

领域约定见 ADR 0012，替代 ADR 0009 中旧的权限、90天实名保留与禁止实名汇总导出条款。
