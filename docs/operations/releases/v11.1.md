# V11.1 · 申领到货自动关联与术语统一

日期：2026-11-24。类型：用户直接要求的小型修改。物资追溯应用升级 V1.2.11。

## 变更摘要

- 到货 & 签收页新增“已核准待关联到货”区域，自动显示审批完成且尚未完全到货的申领单。
- 列表显示申领日期、物料、申领数量、已到货、剩余可到货、申请人和核准人。
- 点击“登记到货”后自动关联对应申领单，带出物料、已到货数量和剩余可到货数量。
- 申领台账中的已核准记录新增“登记到货”快捷按钮，可直接跳转到关联到货登记。
- 仪表盘待办中的“待到货”改为直接打开对应申领单的到货登记。
- 不自动生成虚假到货记录；只有实际登记到货后才写入到货数据。
- 工作台所有用户可见的“采购”字样统一修改为“申领”，包括导航、标题、按钮、表头、状态、提示、日志说明和导出内容。
- 保留部门名称“采购部”及旧模板导入兼容别名，不影响历史文件导入。

## 验证范围

- 已核准申领单自动出现在到货页待关联区域。
- 部分到货申领单正确显示已到货和剩余可到货数量。
- 点击待关联申领单后自动选中关联申领单、物料和可登记数量。
- 登记到货后剩余数量实时更新。
- 工作台可见内容中不再出现“采购”字样（部门名称“采购部”除外）。
