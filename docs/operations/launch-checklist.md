# 品集｜Q Nexus 正式上线验收清单

> 关联：`docs/requirements/acceptance-criteria.md`。自动化覆盖项在对应模块/e2e 测试中验证；
> 下列为需要人工在接近正式环境的 Mac Studio 上确认的项目。

## A. 内容与账号

- [ ] 六个新人阶段均有说明和至少一个有效步骤
- [ ] 至少 12 篇新人必读、20 篇品质知识、8 篇散热与 TVC 文章、10 个有效模板、5 本推荐书目已发布
- [ ] 首页没有空模块
- [ ] 两名有效管理员已完成首次改密（AUTH-11）
- [ ] 数据库与日志检查不到明文密码（AUTH-03）

## B. 角色与权限

- [ ] 阅读者不能进入编辑、用户、审计、备份或运行管理页面
- [ ] 编辑者能维护内容与统计聚合，但不能创建账号或查看身份化明细
- [ ] 管理员能完成账号、栏目、回收站、导入导出与备份管理
- [ ] 停用账号后不能登录，历史署名保留（AUTH-08）
- [ ] 拒绝停用当前登录管理员与最后一名有效管理员（AUTH-09）

## C. 搜索、收藏、反馈与统计

- [ ] 搜索标题/摘要/正文与别名（标准差/σ/Sigma）可命中
- [ ] 快速面板键盘可用；无结果时显示知识缺口入口
- [ ] 收藏仅本人可见；取消后正确消失
- [ ] 五类反馈可提交并由编辑者处理为已解决/忽略
- [ ] 同一用户 30 分钟内重复打开同一文章只计一次阅读
- [ ] 编辑预览/管理员预览不计入阅读统计
- [ ] 7/30/90 天与全部触达人数正确；90 天身份明细仅管理员可见
- [ ] 管理界面显示统计用途声明（STAT-10）；不提供名单导出

## D. 导入导出、回收站与审计

- [ ] 单篇 .md 与 ZIP 导入为草稿；批量导入先预检不覆盖
- [ ] 单篇与全站 Markdown 导出在普通工具中可读，模板独立导出
- [ ] 归档内容 30 天内可恢复；到期后才允许永久删除
- [ ] 永久清理不删除仍被历史版本引用的文件
- [ ] 审计日志 append-only 且至少保留一年；恢复/归档/发布留痕

## E. 备份、恢复与可用性

- [ ] 每日自动备份执行成功并写入管理后台（BKP-05）
- [ ] 保留策略满足 7 份每日 + 8 份每周（BKP-02）
- [ ] 备份已加密，两名管理员知道密钥保管位置（BKP-04）
- [ ] 备份目标配置为公司服务器或移动硬盘（BKP-03）
- [ ] 季度完整恢复演练完成并验证登录/搜索/阅读/下载（BKP-06）
- [ ] 更新流程按 runbook 演练一次（备份→加载→迁移→健康检查→失败回退，OPS-10）
- [ ] 服务错误日志轮转 30 天（OPS-12）

## F. 部署、浏览器与无障碍

- [ ] 仅内网访问；固定 IP 由路由器/DHCP 保留（SEC-01/OPS-08）
- [ ] 外网断开后登录、搜索、编辑、阅读、下载完整可用（OPS-06）
- [ ] Mac Studio 重启后容器自动启动（OPS-07）
- [ ] Chrome/Edge/Safari 桌面核心路径通过；阅读路径 390px 与 200% 放大无溢出
- [ ] 仅键盘可完成登录、搜索、阅读、收藏、反馈与主要后台操作
- [ ] 正文 ≥16px；焦点状态清晰；状态不只靠颜色
- [ ] 运行时无外部字体/CDN/第三方认证依赖

## G. 试运行（1–2 周）

- [ ] 覆盖 1 名新人、2–3 名阅读者、2 名编辑者、2 名管理员
- [ ] 试用覆盖登录、搜索、阅读、收藏、反馈、发布、模板更新、主机重启、备份恢复
- [ ] 阻断上线问题已关闭或有明确接受延期决定
