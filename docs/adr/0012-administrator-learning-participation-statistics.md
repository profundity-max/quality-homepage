# ADR 0012: 管理员学习参与统计

- Status: Accepted
- Date: 2026-10-21
- Supersedes: ADR 0009 的访问权限、实名学习记录保留期与实名汇总导出约定
- 用户确认：docs/superpowers/specs/2026-10-20-learning-statistics.md

## 决定

1. 统计页面、旧聚合接口、实名明细和汇总导出统一仅管理员可用。使用投入主要用于人员培养、辅助评优，不自动合成积分，也不证明学习成效。无首次登录说明弹窗。账号管理可显式将测试账号排除；编辑、管理员和停用成员均纳入正式成员。
2. 总览、人员、内容三视图使用上海自然日，默认本月，支持本季度、本年度和最多两年的自定义日期。姓名搜索影响全部汇总；人员/文章/模板明细筛选不改变上方汇总。最近登录、最近活跃限定所选区间。各类明细每页25条，稳定排序、独立总条数、同步翻页。
3. 所有前台阅读入口（含主题内联正文）在实际可见、有焦点时采集，仅最可见一篇文章计时。隐藏、失焦、离页和连续5分钟无交互暂停。10秒心跳，服务端时间和20秒有效租约限制补计；用户行锁、请求顺序和序列重试去重防止跨文章/跨标签重叠。不接受客户端提供身份或秒数。
4. 用户/文章30分钟内共享访问及有效阅读会话，累计活跃30秒计有效阅读。访问次数、有效次数、有效篇数分别展示。时长按区间内计时片段汇总，资格按区间内达到30秒时间归属；跨日会话可在后一天有效且访问仍归前一天，明细补入其关联访问，便于核对。停点结算剩余有效租约时间；断网/超时不推定持续阅读。
5. 收藏只统计当前数量，取消后减少，不恢复历史累计或向管理员展示个人收藏清单。模板以服务端成功返回文件计下载，跨全部版本统计次数和人数，不能证明保存或使用。登录只统计成功认证，自动续期不计。
6. `reading_started_at` 在0018迁移首次执行时持久化，不因重复迁移/重启重设。历史访问、下载、登录按已有记录展示；历史时长和有效阅读无法补算，完全早于采集起点的区间标为“未采集”，跨起点明确提示只包含已采集部分。历史已按旧90天规则删除的记录无法恢复；早期阅读也曾排除编辑和管理员，不追造该历史。
7. 实名阅读、搜索、下载及计时统计细节保留两年，报表读取也限制两年。Node进程启动30秒后及每天自动清理，也可管理员/CLI执行；清理截止时间不能晚于两年前，匿名累计和聚合不改写。身份与内容审计仍遵守各自独立的不可变审计策略（例如登录安全审计、模板下载和实名导出审计），不将安全审计删除等同于统计数据清理。
8. 管理员可导出当前日期/姓名/排序条件的人员汇总XLSX，包含统计周期、采集起点、姓名、账号状态和指标；每次导出成功生成后先写审计，再返回文件。逐条阅读和下载明细不导出。所有用户文本写为字面字符串，不执行Excel公式，响应禁止缓存。
9. 停用立即撤销所有会话，恢复同一身份及历史但不复活旧会话。保留既有“内容负责人先重分配”和最后有效管理员保护，启停及测试账号标记均审计。

## 后果

活跃阅读是有误差的参与指标，无法识别是否理解，也不能防止人为模拟交互。服务器仅信任自身时钟；网络断开超过租约时宁可少计、不推造时长。大规模历史明细可进一步移至数据库分组与分页，当前部门规模使用限定时间窗口读取后汇总，避免多表连接放大计数。
