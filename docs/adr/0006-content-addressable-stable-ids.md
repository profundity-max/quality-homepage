# 内容寻址采用不可变稳定标识，显示名可随时修改

## 状态

已接受（Slice 2 T1 起生效）

## 背景

IA-03 要求「页面地址使用不会随标题变化的内部标识；文章、主题或栏目改名不得破坏旧链接」。若链接直接使用显示名称（如 `/topics/方差分析`），任何改名都会使历史链接失效，与需求直接冲突。

## 决策

- 栏目（sections）、主题（topics）、知识文章（articles）各有一个 `stable_id` 列，全局唯一、创建后不可变。
- 页面地址与站内链接只使用 `stable_id`：主题 `?topic=<stableId>`、文章 `/articles/<stableId>`。
- `stable_id` 由显示名称 slug 化生成（英文保留原词，中文等无法转写时退回短随机后缀），撞名时追加序号（如 `anova-1`），由知识管理服务在创建时分配。
- 改名（IA-07）只更新显示名称，不触碰 `stable_id`。

## 后果

- 改名、排序、归档均不破坏旧链接；链接契约是稳定标识而非名称。
- 展示名称可以自由演进，历史链接（书签、文档引用）保持有效。
- 代价：创建时需要生成并保证唯一性；调试时需要将 `stable_id` 映射回显示名（管理后台已提供该视图）。
- 归档不删除数据（IA-07），因此 `stable_id` 在归档后仍可用于旧链接的归档说明页。
