# 统一阅读投影与原子生命周期操作

- 状态：已接受，V5.0 生效
- 来源：2026-10-20 架构巡检及用户要求逐项修复
- 关联：ADR 0004、0007、0008、0010

阅读侧统一查询 `readable_articles`。已发布文章返回当前内容，已发布后进入编辑的草稿返回最后 publish 快照；没有发布快照时不回退工作区。SQL 视图只负责版本选择，检索、收藏和主题排序仍由所属模块负责。文章另存发布时间（published_updated_at），与编辑 revision 分离；快照新增别名和源更新时间，防止草稿别名泄漏和编辑活动变成“最近发布”；历史缺失值不凭当前草稿猜测。

知识文章编辑模块内部使用事务和文章行锁，保存与发布必须携带更新时间，编辑占用也在写入时校验。占用接管使旧更新时间失效，客户端仅凭页面的只读状态不能绕过校验。保存允许局部内容更新，省略字段保留原值，避免自动保存承担完整元数据装配知识。不引入心跳或超时释放。

生命周期操作在各所属模块的事务中同时完成状态与内容审计，复用已有 DatabaseConnection；不引入跨业务的通用事务或 repository 框架。模板发布锁定模板行，配合唯一有效版本索引。数据库事务不承诺回滚文件与扫描等外部效果。

备份恢复的 operational 模块拥有完整恢复演练流程，CLI 与后台只负责各自输入、连接及输出；复用已有文件、命令和恢复 adapter。

本决策补充 ADR 0007：其“并发发布无事务锁”的初始限制在 V5.0 由文章行锁和原子提交取代；其单行工作区与发布快照模型保持不变。恢复历史版本也必须先保留正在对外发布的内容，再写入恢复草稿。
