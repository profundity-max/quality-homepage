# 后台采用结构化控制台

2026-10-22，用户在三套视觉方案中选择「结构化控制台」，确认账户管理、文章管理、学习统计细化稿后要求实施。

后台沿用 Editorial Space 的灰度层级、字体栈、主题和品牌，但采用固定深色分组侧栏、浅色工作区和更紧凑的表格。后台标题30px，正文与表格14–15px，控件40px起；主按钮使用局部钴蓝 #1D4ED8 配白字，普通操作使用描边或文字。此决定细化 ADR 0003 中允许后台采用更高信息密度的约定，并替代其中后台主按钮可直接使用 #0096FF 的建议。阅读门户和正文令牌不变。

后台导航按内容管理、人员与统计、系统维护分组，权限过滤继续由角色决定，服务端鉴权仍是实际权限边界。移动端采用可展开导航，页面切换后收起。表格允许容器内横向滚动，页面本身不横向溢出。

账户列表采用筛选与每页20条分页；新建、身份/角色编辑和更多操作按需进入原生模态对话框，保留独立表单及操作审计。停用、恢复、密码重置、解锁和测试账号排除均沿用既有服务。账号统计排除不影响账户列表可见性。

文章按标题/主题、负责人、发布状态、复核日期对齐。发布状态仍只有草稿、已发布、已归档；待复核是复核提醒，不能伪装成新发布状态。归档时再填写原因；待复核任务移入文章管理。

学习统计总览先展示四项核心指标和最多六人的摘要，访问与登录汇总仍可见。人员、内容、实名明细、每日数据、导出和保留策略保持，长口径说明与每日趋势按需展开。不合成学习分，不从图片示例导入任何账号或行为数据。

所有页面继续使用真实服务端数据。图中的头像、演示人数、日期和文案不是额外功能需求；实现保留现有主题筛选语义和真实账号名称。无新依赖、数据库迁移或采集口径变化。
