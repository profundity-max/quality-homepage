# 采用 Editorial Space 作为正式视觉方向

品集｜Q Nexus 采用 UI 原型中的 **A：Editorial Space** 作为正式视觉方向。页面以宽松留白、编辑式编排和部门手册感为核心，使用灰度承担结构层级，并将 `#0096FF` 限制在焦点、选中状态和少量关键强调中。

该方向适用于阅读门户、Markdown 编辑器和管理后台，但三类界面使用不同的信息密度：门户保持安静和内容优先，编辑器保持正文优先，后台允许更紧凑的表格与批量操作。它们共享颜色、排版、图标、控件和交互规则，不形成三个独立产品。

原型分支 `prototype/q-nexus-ui` 及提交 `8a5ab9a` 只作为视觉证据，不作为生产实现来源。正式实现必须重新建立可访问、可测试和可维护的 UI 模块，不直接合并 throwaway 原型代码。B：Knowledge Atlas 和 C：Focus Studio 不作为全站主方向；其中知识分类树、搜索聚焦等能力仍按产品需求在 A 的视觉语言内实现。
