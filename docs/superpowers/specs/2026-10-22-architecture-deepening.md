# V7.0 架构深化设计

用户已授权按 2026-10-22 架构报告逐项优化。目标是提高时序行为的可验证性，并避免统计用途捆绑无用计算。

## 1. 活跃阅读

新增不依赖 DOM 的活跃阅读 module，拥有当前文章、交互时间、暂停修订、心跳节流、序列和请求排序。浏览器 adapter 负责采样可见文章、焦点、可见性及注册事件。保留10秒采样、9秒节流容差、5分钟闲置和离页 keepalive；服务器仍是身份与计时事实的唯一权威。

测试 seam 为完整阅读会话：受控时钟、采样和请求执行，观察发送顺序；覆盖在途请求时暂停、切换时离页、恢复、闲置、定时抖动、失败及销毁。

## 2. 学习统计

共享权限、过滤和人员口径，人员汇总路径不构建内容、趋势和明细，也不读取不需要的文章与模板元数据。完整报表保留已有行为；使用分组索引避免按人、文章、日重复扫描全部记录。知识缺口独立读取，不因一个字段执行旧 dashboard 全部查询。保留上海日期、跨午夜关联、两年保留、空值、姓名筛选和导出审计。此轮不增加通用数据库 adapter，不重构为多表巨型连接。

测试 seam 为报表与人员导出：人员汇总与完整报表一致，导出不读取内容元数据；已有跨日、分页和授权回归继续通过。

## 3. 编辑草稿

编辑草稿会话 module 拥有自动保存、保存中继续输入、本地恢复、冲突、revision 和成功后的清理时机。UI adapter 负责表单提交、当前正文采样、提示和用户选择。保存成功仅清理对应已保存内容，保留随后输入或断网产生的新草稿；已销毁会话不更新 UI。复用现有本地存储实现，服务器事务、编辑占用和版本校验仍遵守 ADR 0011。

测试 seam 为完整草稿会话：观察保存输入、本地恢复内容、revision 与冲突结果；覆盖在途编辑、断网、失败、接管、恢复选择及销毁。
