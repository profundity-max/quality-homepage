# 品集｜Q Nexus 视觉设计规范

> 状态：已确认  
> 关联需求：[产品需求规格](./product-requirements.md)

## 1. 设计方向

品集｜Q Nexus 采用接近 Apple 官网的冷静、克制和宽松节奏，以灰度层次、精确网格和清晰排版构建专业感。视觉首先服务知识阅读与查找，其次才表达品质工程与散热技术特色。

### 1.1 关键词

- 清晰、可靠、专业
- 温暖但不过度亲昵
- 现代、克制、有辨识度
- 内容优先
- 精确对齐与充分留白

### 1.2 禁止方向

- 传统 OA 或通用企业后台模板感
- 纯黑背景与过强黑白反差
- 大面积渐变、玻璃拟态或发光效果
- 卡通插画、Emoji 导航或图库人物照片
- 密集仪表盘、无意义统计图和全页卡片化
- 自动轮播、背景视频、视差滚动和花哨转场
- 用不同高饱和颜色区分每个一级模块

## 2. 色彩系统

### 2.1 原则

- 灰度承担页面结构与内容层级。
- `#0096FF` 是唯一品牌强调蓝，仅用于交互、焦点和少量关键视觉。
- 强调蓝占单个页面的感知面积应保持克制，通常不超过约 10%。
- 普通小号链接文字不得机械使用 `#0096FF`；应根据背景选择满足 WCAG AA 的更深或更浅蓝色变体。
- 成功、警告、错误只使用低饱和语义色，并同时配合文字或图标，不只依赖颜色。

### 2.2 浅色模式建议令牌

| 用途 | 建议颜色 | 说明 |
| --- | --- | --- |
| 页面背景 | `#F5F5F7` | 柔和浅灰，不使用大面积刺眼纯白 |
| 一级内容表面 | `#FFFFFF` | 文章、搜索面板、弹窗等 |
| 次级表面 | `#FAFAFA` | 工具栏、弱分区 |
| 主文字 | `#1D1D1F` | 深炭灰，不使用纯黑 |
| 次要文字 | `#6E6E73` | 描述与元数据 |
| 弱文字 | `#86868B` | 辅助信息，仍须满足适用对比度 |
| 分隔线 | `#D2D2D7` | 使用细线与低对比度 |
| 强调蓝 | `#0096FF` | 图标、焦点、选中、大号强调元素 |
| 深色链接蓝 | 设计阶段校准 | 必须在白底满足 WCAG AA |
| 警告 | 低饱和暖橙 | 仅用于风险与异常 |

### 2.3 深色模式建议令牌

| 用途 | 说明 |
| --- | --- |
| 页面背景 | 深炭灰，不使用 `#000000` |
| 内容表面 | 比背景略浅一层，依靠灰阶而非强阴影分层 |
| 主文字 | 柔和近白，不使用刺眼纯白作为大段正文 |
| 次要文字 | 中性灰，保持层级与对比度 |
| 分隔线 | 低对比灰，避免发光边框 |
| 强调蓝 | 使用比浅色模式略亮的可访问变体 |

深色模式不是浅色模式的简单反色，需单独校准表面、文字、阴影和语义色。

## 3. 字体与排版

### 3.1 字体栈

```css
font-family: Helvetica, Arial, system-ui, -apple-system, "Segoe UI", sans-serif;
```

- macOS 优先 Helvetica。
- Windows 回退 Arial。
- 其他环境使用系统无衬线字体。
- 不依赖 Google Fonts 或其他外部字体服务。
- 数据、公式、代码和版本号可使用本地等宽字体栈。

### 3.2 排版规则

- 正文默认不小于 16px，采用宽松行距。
- 普通正文行长控制在舒适阅读范围，中栏约 720–800px。
- 标题使用层级、字号和留白建立节奏，不依赖极粗字重。
- 英文术语保持正常大小写，不使用大面积全大写。
- 数字和版本号使用等宽数字特性，便于比较。
- 正文、表格、公式和图片之间保持清晰的垂直节奏。

## 4. 布局与导航

### 4.1 全站骨架

- 顶部主导航承载一级模块。
- 桌面端顶部导航吸附；向下滚动时缩小高度，并保留搜索入口。
- 手机端使用简洁顶栏与抽屉导航。
- 品质知识和散热知识采用三栏结构：左侧分类树、中间正文、右侧文章目录。
- 左侧分类树可收起并独立滚动；右侧目录可在较窄屏幕隐藏。
- 手机端左右栏进入抽屉，中间正文占满可用宽度。

### 4.2 首页节奏

首页按以下区块纵向排列：

1. 问候、理念和全站搜索
2. 新人学习大入口
3. 常用模板、品质知识、散热知识和推荐书单的编辑式入口
4. 最近更新
5. 精选推荐书籍
6. 简洁页脚

- 首屏问候区约占视口高度 55%–65%，并露出下一模块的一部分。
- 一屏主要表达一件事，区块之间使用明显留白。
- 核心入口采用大小有变化的编辑式版面，不使用整齐排列的同尺寸后台卡片网格。
- 首页不展示复杂目录树或内容统计看板。

## 5. 图形语言

- 使用统一的细线图标，不使用 Emoji。
- 装饰图形只使用灰阶和少量强调蓝。
- 品质知识可使用网格、分布曲线或控制图抽象线条。
- 散热知识可使用等温线或热流路径。
- 模板中心可使用文档层叠轮廓。
- 新人专区可使用有顺序的路径节点。
- 推荐书单可使用简洁书脊或页面轮廓。
- 不使用大型背景图、图库照片或装饰性产品照片。
- 真实工艺、产品和实验照片只服务具体文章内容。

## 6. 表面、圆角与阴影

- 搜索框、主要入口、图片、弹窗和重要控件使用中等圆角。
- 普通正文、列表和每一个信息块不得全部套入卡片。
- 阴影只用于浮层或需要表达层级的少数元素，强度极轻。
- 常规分区优先使用留白、背景灰阶和细分隔线。
- 深色模式不使用发光阴影。

## 7. 搜索体验

- 首页搜索框是首屏主交互。
- 激活后打开居中快速搜索面板，而非在首页直接展开结果。
- 面板支持键盘上下选择与回车进入。
- 结果按文章、主题、模板和书籍分组。
- 面板可显示最近搜索和收藏入口。
- 完整结果页提供栏目、标签、内容类型和更新时间筛选。
- 无结果时显示别名建议和知识反馈入口。
- 搜索匹配词使用克制高亮，不影响段落可读性。

## 8. 知识阅读页

内容顺序：

1. 面包屑与主题
2. 标题与摘要
3. 负责人、更新时间和复核日期
4. 正文目录
5. Markdown 正文
6. 标签与相关文章
7. 阅读次数、收藏与内容反馈
8. 上一篇与下一篇

表现规则：

- 正文中栏不随超宽屏无限拉宽。
- 大表格、统计图和必要图片可临时突破正文宽度。
- 普通表格使用浅分隔线与行间留白，不使用厚重全网格。
- 宽表格允许横向滚动，首列可按需固定。
- 公式居中展示，编号靠右。
- 控制图和统计图采用灰阶坐标、`#0096FF` 主数据线；警戒线和异常点才使用暖色。
- 不使用三维、渐变或彩虹色图表。

## 9. Callout

六种类型共享一致结构：图标、标题和正文。

| 类型 | 视觉处理 |
| --- | --- |
| 信息 | 灰阶基础 + 信息图标 |
| 提示 | 灰阶基础 + 提示图标 |
| 重点 | `#0096FF` 左侧窄条或图标，不使用大面积蓝底 |
| 警告 | 低饱和暖橙窄条或图标 |
| 示例 | 灰阶基础 + 示例图标 |
| 公式 | 灰阶基础 + 公式图标 |

- 所有 Callout 使用淡灰背景、细边线和克制圆角。
- 类型差异不能只通过颜色表达。
- 深色模式不得出现发光边缘。

## 10. Markdown 编辑器

- 默认单栏即时预览。
- 支持切换 Markdown 源码和左右分栏。
- 常用格式保留在精简顶部工具栏，其他命令放入命令菜单。
- 左侧可打开文章大纲；右侧显示主题、标签、负责人、复核日期和发布状态。
- 自动保存状态和最后保存时间始终可见，但不抢占正文注意力。
- 冲突、离线和扫描状态使用明确图标与文字提示。
- 编辑器与阅读页共享 Markdown 渲染样式，减少发布前后差异。

## 11. 后台密度

- 阅读门户：宽松、安静、内容优先。
- 编辑器：正文优先，工具按需出现。
- 管理后台：提高密度，支持表格、筛选、批量操作和状态汇总。
- 三者使用相同颜色、字体、控件和图标体系，不形成三个独立产品。

## 12. 动效

- 按钮、下拉、卡片和浮层反馈控制在 150–250ms。
- 页面切换不使用全屏转场。
- 首页区块允许轻微淡入，但不得阻塞滚动或内容出现。
- 禁止自动轮播、背景视频和视差滚动。
- 完整尊重系统“减少动态效果”设置。

## 13. 无障碍

- 所有正文和控件满足产品需求中的 WCAG AA、键盘和 200% 放大要求。
- 焦点环优先使用 `#0096FF` 或其可访问变体，并保留足够外边距。
- 选中、警告、错误和成功状态必须同时使用文字或图标。
- 图片上传时提供替代文字字段；装饰图形不得被屏幕阅读器重复朗读。
- 可点击区域在触控设备上保留足够尺寸和间距。

## 14. 高保真验收页

实施全站前必须先完成以下三个高保真界面：

1. 登录后首页
2. 品质知识文章阅读页
3. Markdown 文章编辑页

三页需同时提供关键桌面宽度下的浅色和深色状态，并至少展示一次手机响应式处理。确认以下内容后才扩展全站：

- 灰度层次与强调蓝用量
- Helvetica / Arial 字体栈的中英文表现
- 首页首屏高度和区块节奏
- 顶部导航、左侧分类树和右侧目录关系
- 长文、表格、公式、Callout 和图片表现
- 编辑器即时预览、源码切换和属性面板
- 键盘焦点、对比度与减少动态效果
