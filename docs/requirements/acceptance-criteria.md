# 品集｜Q Nexus 上线验收标准

> 状态：已确认  
> 关联需求：[产品需求规格](./product-requirements.md)  
> 视觉规范：[视觉设计规范](./visual-design-specification.md)

## 1. 验收原则

1. 只有内容闭环和治理闭环均完成，才进入正式上线验收。
2. 所有严重安全、数据丢失、权限越权和备份恢复问题必须关闭。
3. 验收使用接近正式环境的 Mac Studio、固定局域网 IP、真实浏览器和代表性内容。
4. 自动化测试结果不能替代人工体验、无障碍和恢复演练。

## 2. 上线门槛

- [ ] 六个新人阶段均有说明和至少一个有效步骤。
- [ ] 至少 12 篇新人必读文章已发布。
- [ ] 至少 20 篇品质知识文章已发布。
- [ ] 至少 8 篇散热与 TVC 文章已发布。
- [ ] 至少 10 个有效模板可下载。
- [ ] 至少 5 本推荐书目已发布。
- [ ] 首页没有空模块。
- [ ] 两名有效网站管理员已创建并完成首次改密。
- [ ] 固定局域网 IP 已配置。
- [ ] 公司服务器或移动硬盘备份目标已配置。

## 3. 角色与账号

- [ ] 阅读者不能进入编辑、用户、审计、备份或运行管理页面。
- [ ] 编辑者能维护内容，但不能创建账号、修改角色或查看身份化搜索和触达明细。
- [ ] 管理员可以完成账号、角色、栏目、回收站、导入导出和备份管理。
- [ ] 新账号首次登录被强制修改临时密码。
- [ ] 数据库与日志检查不到明文密码。
- [ ] 连续失败登录触发临时锁定，管理员可安全解锁。
- [ ] 强制退出所有设备后，旧登录会话失效。
- [ ] 系统拒绝停用当前登录管理员及最后一名有效管理员。
- [ ] 停用账号后不能登录，其历史署名仍保留并标记停用。
- [ ] 网站管理员无法仅凭网站角色获得 Mac Studio 登录权限。

## 4. 新人路线

- [ ] 新用户能从首页进入六阶段路线总览。
- [ ] 六个阶段名称和工作理念内容与需求一致。
- [ ] 学习步骤能引用文章和模板，且内容只维护一份。
- [ ] 上一项、下一项、返回总览和“第 N 项 / 共 N 项”导航正确。
- [ ] 系统不保存或展示个人完成率、已读勾选、考试或成绩。
- [ ] 新人专区不出现人员目录或个人联系方式模块。
- [ ] 一名未接受产品说明的试用新人能沿路线找到指定必读内容。

## 5. 栏目、主题与文章

- [ ] 初始栏目与 `栏目体系.md` 一致。
- [ ] 一个主题可包含多篇文章。
- [ ] 一篇文章只能有一个主要主题，并可设置多个标签和别名。
- [ ] 阅读者看不到空主题，编辑后台仍可看到。
- [ ] 主题改名不破坏旧链接。
- [ ] 归档含文章主题时，系统强制迁移文章或连同归档。
- [ ] 缺少标题、摘要、正文、主题、负责人或复核日期时不能发布。
- [ ] 文章阅读页完整展示需求规定的元数据、正文和操作。
- [ ] 归档文章的旧链接显示归档说明，不默认暴露正文。

## 6. Markdown 编辑与版本

- [ ] 即时预览、源码模式和左右分栏均可使用。
- [ ] 标题、表格、图片、代码、LaTeX、Mermaid、内部链接和六种 Callout 正确编辑和渲染。
- [ ] Markdown 中的 JavaScript、iframe、外部脚本和危险 HTML 被阻止或清理。
- [ ] Mermaid 以安全模式运行。
- [ ] 自动保存显示最近保存时间。
- [ ] 模拟断网后草稿仍保存在浏览器；恢复联网后按规则同步。
- [ ] 两个编辑者同时修改不会发生静默覆盖，冲突内容均可恢复。
- [ ] 编辑已发布文章时，阅读者继续看到旧发布版本。
- [ ] 发布新版本后历史完整，恢复历史版本要求填写原因并进入审计。
- [ ] 创建副本后生成新标识和草稿，不继承统计。

## 7. 模板

- [ ] 可上传至少 `.docx`、`.xlsx`、`.pptx`、`.pdf`、`.md`、`.key`、`.numbers`、`.xmind` 和未知扩展名文件。
- [ ] 所有模板均强制下载，不在线预览或执行。
- [ ] 超过配置上限的文件被明确拒绝。
- [ ] 文件先进入隔离区，扫描通过前不能发布。
- [ ] 扫描失败或服务不可用时不能设为有效版本，并向管理员显示原因。
- [ ] 发布新版本后，阅读者只看到新有效版本，旧版仍可由编辑者追溯。
- [ ] 已有模板链接在发布新版后下载当前有效版本。
- [ ] 模板页显示扩展名、大小、适用软件、版本和 QMS 受控版本提示。
- [ ] 下载次数、下载人数、上传人和校验值记录正确。

## 8. 搜索、收藏与反馈

- [ ] 搜索标题、摘要和正文能找到文章。
- [ ] 搜索“标准差”“σ”或“Sigma”能命中配置了对应别名的同一知识。
- [ ] 搜索能按文章、主题、模板和书籍分组，并支持结果页筛选。
- [ ] 模板搜索不读取文件内部内容。
- [ ] 快速搜索支持键盘上下选择和回车。
- [ ] 无结果时显示知识反馈入口并留下搜索记录。
- [ ] 收藏仅当前用户可见，取消收藏后正确消失。
- [ ] 五种内容反馈均可提交，并能由编辑者处理为已解决或忽略。
- [ ] 系统没有公开评论区或最近阅读列表。

## 9. 统计与隐私

- [ ] 同一用户 30 分钟内重复打开同一文章只增加一次阅读。
- [ ] 编辑预览、管理员预览和自动化检查不计入统计。
- [ ] 7、30、90 天和全部时间触达人数按账号正确去重。
- [ ] 编辑者只能查看聚合统计，管理员才可查看 90 天内身份明细。
- [ ] 管理界面不提供触达人员名单导出。
- [ ] 90 天后的身份化明细被清理，聚合统计仍保留。
- [ ] 管理界面明确显示统计用途声明。
- [ ] 热门、高触达、增长、无人阅读、搜索后打开、无结果搜索和模板下载指标可用。

## 10. 导入、导出与可迁移性

- [ ] 单个 Markdown 文件和含图片 ZIP 包可导入为草稿。
- [ ] 批量导入先显示新增、跳过和冲突预检，不覆盖现有内容。
- [ ] 导入内容缺少必要发布字段时不能发布。
- [ ] 单篇文章导出包在普通 Markdown 工具中可阅读，图片引用有效。
- [ ] 全站导出包含文章、栏目、主题、标签、别名和 YAML frontmatter 元数据。
- [ ] 模板作为独立文件导出，不嵌入 Markdown。
- [ ] 导出内容不依赖当前网站或外部 CDN 才能读取。

## 11. 复核、归档与审计

- [ ] 复核到期产生后台提醒，但内容仍可阅读。
- [ ] “确认仍然有效”更新复核日期、留下审计且不产生正文新版本。
- [ ] 停用负责人时可重新分配或进入待重新分配队列。
- [ ] 日常删除进入归档或回收站，30 天内可恢复。
- [ ] 永久清理不删除仍被历史版本引用的文件。
- [ ] 登录、账号、角色、内容、栏目、模板、搜索、备份和恢复操作均进入审计范围。
- [ ] 审计日志不能通过普通后台操作修改。

## 12. 视觉与响应式

- [ ] 首页、文章阅读页和 Markdown 编辑页高保真设计已先行确认。
- [ ] 浅色和深色模式均不使用纯黑主背景。
- [ ] `#0096FF` 使用克制，普通链接和按钮对比度满足 WCAG AA。
- [ ] macOS 使用 Helvetica，Windows 回退 Arial，无外部字体依赖。
- [ ] 首页首屏约占视口 55%–65%，并露出下一模块。
- [ ] 桌面知识页左侧分类树、中间正文、右侧目录关系清晰。
- [ ] 手机端可完成阅读、搜索、收藏和模板下载。
- [ ] 页面没有传统 OA、玻璃拟态、重渐变、自动轮播或背景视频。
- [ ] 动画遵守系统减少动态效果设置。

## 13. 无障碍与浏览器

- [ ] 最新版 Chrome、Edge 和 Safari 桌面端核心路径通过。
- [ ] 仅用键盘可完成登录、搜索、阅读、收藏、反馈和主要后台操作。
- [ ] 所有焦点状态清晰可见。
- [ ] 状态不只依赖颜色表达。
- [ ] 浏览器放大到 200% 后核心内容不丢失，操作仍可完成。
- [ ] 正文默认字号不小于 16px。
- [ ] 内容图像有替代文字，装饰图不产生冗余朗读。

## 14. 部署、安全与离线运行

- [ ] 服务仅从公司局域网访问，公网无法直接连接。
- [ ] 固定局域网 IP 工作稳定且无地址冲突。
- [ ] HTTP 登录页显示受信任局域网提示。
- [ ] 外网断开后仍可登录、搜索、编辑、阅读和下载。
- [ ] 运行时没有 Google Fonts、CDN、外部封面或第三方认证依赖。
- [ ] 数据目录不能绕过登录直接访问。
- [ ] 图片类型、大小与 SVG 清理符合安全要求。
- [ ] 案例文章未确认脱敏时不能发布。
- [ ] 禁止内容类型和 QMS 边界提示已体现在管理流程中。
- [ ] 服务错误日志按 30 天策略轮转。

## 15. 重启、备份与恢复演练

- [ ] Mac Studio 重启后容器自动启动，网站无需人工输入命令即可恢复。
- [ ] 服务进程异常退出后自动重启，并在管理摘要中留下告警。
- [ ] 每日备份任务能覆盖数据库、文章、版本、图片和模板。
- [ ] 保留策略满足 7 份每日和 8 份每周备份。
- [ ] 备份已加密并写入公司服务器或移动硬盘，而非只留在 Mac Studio。
- [ ] 管理后台显示最近备份结果和失败原因。
- [ ] 在临时环境完整恢复后，可使用恢复账号登录、搜索文章、阅读正文并下载模板。
- [ ] 更新失败时旧版本保持可用或能按文档恢复。

## 16. 小范围试用结论

- [ ] 试用持续 1–2 周，并包含新人、阅读者、编辑者和管理员代表。
- [ ] 新人无需口头讲解即可沿六阶段路线找到指定内容。
- [ ] 阅读者能通过搜索或栏目找到指定知识和模板。
- [ ] 编辑者无需修改代码即可完成创建、发布、复核和归档。
- [ ] 管理员完成账号管理、模板更新、备份检查和恢复演练。
- [ ] 试用中发现的阻断上线问题已关闭或有用户明确接受的延期决定。
