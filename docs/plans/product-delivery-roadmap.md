# 品集｜Q Nexus 交付路线

> 状态：已规划
> 原则：每个切片都形成可运行、可测试的软件；前一切片通过后再进入下一切片。

## Slice 1：基础、身份与 Editorial Space 门户骨架

交付 Next.js/TypeScript 基线、PostgreSQL migration、本地账号与安全会话、首次管理员命令、首次改密、角色保护、A 风格全站骨架和个性化首页问候。Docker Compose 可在 Mac Studio 同类环境启动，且外网断开后登录和首页仍可用。

验收重点：AUTH-01 至 AUTH-12 的登录相关路径、HOME-01/02、Editorial Space 令牌、键盘焦点、浅深色、桌面与移动端、健康检查。

## Slice 2：栏目与知识阅读闭环

交付初始栏目导入、主题与别名、文章模型、已发布版本读取、品质知识/散热知识入口、文章三栏阅读页和统一安全 Markdown 渲染器。首页开始读取真实的知识入口与最近更新。

验收重点：IA-01 至 IA-09、ART-01 至 ART-07 的阅读部分、Markdown 安全、稳定链接、空主题可见性。

## Slice 3：Markdown 编辑与发布闭环

交付三种编辑模式、自动保存、离线临时草稿、冲突/占用、图片、发布字段校验、已发布内容的独立草稿和基础版本历史。编辑者可在不修改代码的情况下创建和发布真实文章。

验收重点：EDIT-01 至 EDIT-10、VER-01 至 VER-07、GOV-01 至 GOV-05，以及正式首页/文章/编辑器高保真复核。

## Slice 4：新人路线、模板中心与推荐书目

交付六阶段新人路线、模板隔离上传与当前有效版本、强制下载、本地扫描、推荐书目和首页相应真实内容。该切片完成后达到“内容闭环”，可开始集中录入首批内容但不能正式上线。

验收重点：ONB、TPL、FILE、BOOK 全部需求和最低内容准备入口。

## Slice 5：搜索、收藏、反馈与内容统计

交付快速搜索、完整结果筛选、别名匹配、搜索记录、收藏、五类反馈、阅读次数、触达人数和权限分级的统计看板。

验收重点：SEARCH、FAV、FDBK、STAT 全部需求，尤其 30 分钟去重、90 天身份保留和禁止绩效用途。

## Slice 6：治理、迁移、审计与运行保障

交付完整历史恢复、复核与负责人交接、回收站、Markdown 导入导出、审计、文件引用保护、自动备份、恢复演练、告警、日志轮转和安全清理。完成内容填充与 1–2 周试运行后进入正式上线验收。

验收重点：PORT、DEL、AUDIT、SEC、OPS、BKP、AVL 全部需求及完整上线验收清单。

## 每个切片的共同完成定义

- 对应需求编号有自动测试或明确的人工验收记录。
- 代码格式、lint、类型检查、单元/模块测试、Playwright 和生产 build 全部通过。
- 不依赖外部字体、CDN、图片、登录或运行时服务。
- Chrome、Edge、Safari 桌面核心路径通过；阅读路径完成 390px 和 200% 放大检查。
- 新增业务词汇同步 `CONTEXT.md`；新增难以逆转决定同步 ADR。
- GitHub Issue 写明验收证据、剩余风险和下一切片入口。
