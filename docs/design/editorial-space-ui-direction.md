> 视觉证据：`prototype/q-nexus-ui` 分支，提交 `8a5ab9a`

## 1. 设计承诺

Editorial Space 把品集｜Q Nexus 设计成一份持续更新的品质部门手册，而不是传统 OA、文件盘或管理看板。

- **宽松**：一屏主要表达一件事，使用留白和阅读节奏建立层级。
- **编辑式**：入口大小、文字和抽象图形根据内容重要性编排，不采用等尺寸卡片网格。
- **手册感**：分类、编号、元数据和正文目录帮助用户定位，但不压过内容本身。
- **冷静克制**：浅灰背景、近黑文字和细分隔线承担结构；蓝色只表达交互与重点。
- **内容优先**：装饰图形来自品质与散热知识本身，不使用图库照片或泛化插画。

## 3. 正式令牌

### 3.1 颜色

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--color-canvas` | `#F5F5F7` | `#1C1C1E` | 页面背景 |
| `--color-surface` | `#FFFFFF` | `#252527` | 搜索面板、弹窗和主要浮层 |
| `--color-surface-muted` | `#FAFAFA` | `#2C2C2E` | 工具栏和弱分区 |
| `--color-text` | `#1D1D1F` | `#F3F3F5` | 标题和正文 |
| `--color-text-secondary` | `#525256` | `#D0D0D5` | 摘要和次要正文 |
| `--color-text-muted` | `#6E6E73` | `#A0A0A8` | 元数据；具体字号必须通过 AA 校验 |
| `--color-divider` | `#D2D2D7` | `#45454A` | 细分隔线 |
| `--color-accent` | `#0096FF` | `#38AAFF` | 焦点、选中和大号重点元素 |
| `--color-link` | `#006BB8` | `#70C2FF` | 小号文字链接，满足 WCAG AA |
| `--color-warning` | `#A85D1D` | `#E6A062` | 警告图标和窄条，必须同时显示文字 |

强调蓝的感知面积通常不超过单页约 10%。主按钮可以使用强调蓝；正文链接、状态与图表不得机械地全部使用强调蓝。

### 3.2 排版与间距

- 字体栈：`Helvetica, Arial, system-ui, -apple-system, "Segoe UI", sans-serif`。
- 正文基准：桌面与移动均不小于 `16px`，行高 `1.7` 左右。
- 阅读正文：常规宽度 `720–800px`；必要表格和图形可扩展到 `1040px`。
- 页面内容最大宽度：`1440px`；左右安全边距桌面至少 `48px`，移动端 `20px`。
- 标题尺度：首屏问候使用流式 `clamp(3rem, 7vw, 6.5rem)`；文章标题使用 `clamp(2.5rem, 5vw, 5rem)`。
- 间距采用 `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128px` 序列。
- 中等圆角用于搜索框、浮层和重要控件；普通正文段落与列表不套卡片。

## 4. 全站信息架构

顶部一级导航的固定顺序为：

1. 首页
2. 新人专区
3. 品质知识
4. 散热知识
5. 推荐书单
6. 模板中心

右侧固定提供搜索和用户菜单。编辑者或管理员进入后台时仍保留产品品牌与返回门户入口，但后台使用更高密度的二级导航。

### 4.1 URL 结构

| 内容 | 稳定路径 |
| --- | --- |
| 首页 | `/` |
| 登录 | `/login` |
| 新人路线总览 | `/onboarding` |
| 新人路线步骤 | `/onboarding/{stageId}/{stepId}` |
| 品质知识 | `/quality` |
| 散热知识 | `/thermal` |
| 主题 | `/topics/{topicId}` |
| 知识文章 | `/articles/{articleId}` |
| 推荐书单 | `/books` |
| 书目详情 | `/books/{bookId}` |
| 模板中心 | `/templates` |
| 模板详情 | `/templates/{templateId}` |

路径使用不可变内部标识，不将可变标题作为唯一地址依据。

## 5. 三个定义性界面

### 5.1 登录后首页

首页顺序固定为：

1. 按本地时间生成的问候、固定理念和全站搜索
2. 新人六阶段路线大入口
3. 常用模板快捷入口
4. 品质知识入口
5. 散热知识入口
6. 最近更新
7. 推荐书籍
8. 简洁页脚

首页不展示完整分类树、热度看板、管理表格或个人学习进度。编辑者和管理员的工作摘要放在问候区之后的安静提示带中，不抢占普通入口。

### 5.2 知识文章阅读页

桌面端使用左、中、右三栏。左栏是可收起并独立滚动的分类树；中栏承载面包屑、主题、标题、摘要、负责人、更新时间、复核日期、正文及后续操作；右栏是吸附的本页目录。

- `≥ 1280px`：三栏完整显示。
- `960–1279px`：左栏保持，右栏收进“本页目录”按钮。
- `< 960px`：左右栏进入抽屉，正文占满可用宽度。
- 表格在小屏横向滚动，页面本身不得产生横向溢出。
- 重点 Callout 使用蓝色窄条；警告 Callout 使用暖橙窄条；其余类型依靠图标和标题区分。

### 5.3 Markdown 编辑器

默认显示单栏即时预览，并允许切换纯 Markdown 源码与左右分栏。顶部只保留撤销、重做、粗体、斜体、标题、列表、引用、链接、图片和 Callout；其他动作进入命令菜单。

左侧文章大纲和右侧属性面板按需出现。保存状态始终可见但保持安静；离线、冲突、占用和发布检查必须同时使用图标与文字。阅读页和编辑器调用同一个 Markdown 渲染模块，确保预览与发布结果一致。

## 6. UI 模块与接口

正式实现建立以下 UI 模块，调用者只使用其接口，不复制内部样式：

| 模块 | 接口 | 隐藏的实现复杂度 |
| --- | --- | --- |
| `AppShell` | 当前一级入口、用户摘要、页面内容 | 吸附导航、移动抽屉、跳转链接、焦点管理 |
| `ThemeController` | 当前主题和切换动作 | 系统偏好、Cookie 持久化、首屏无闪烁 |
| `SearchLauncher` | 打开搜索、可选初始查询 | 快捷键、焦点圈定、结果面板与恢复焦点 |
| `EditorialSection` | 编号、标题、说明、动作和可选图形 | 响应式编排、间距、图形位置与减少动态效果 |
| `KnowledgeReader` | 已渲染文章模型 | 三栏响应式、目录、宽表格、元数据和操作区 |
| `MarkdownRenderer` | 可信 Markdown 文本和渲染上下文 | 清理、Callout、公式、Mermaid、站内链接和图片 |
| `EditorWorkspace` | 草稿模型、保存与发布动作 | 三种模式、大纲、属性、离线、冲突和占用状态 |

`MarkdownRenderer` 是阅读页和编辑器共同的正式渲染接口，不允许分别实现两套 Markdown 样式或语法解释。

## 7. 设计验收门槛

全站扩展前，正式代码中的首页、文章阅读页和 Markdown 编辑页必须重新通过：

- 1440px 浅色与深色检查；
- 390px 移动端检查；
- 200% 浏览器缩放；
- 键盘全路径和清晰焦点；
- WCAG AA 自动扫描与人工对比度复核；
- Chrome、Edge 和 Safari 最新版核心路径；
- `prefers-reduced-motion: reduce` 下无非必要动效；
- 浏览器控制台零 error、零 warning。

原型通过只确认方向，不替代这些正式验收。
